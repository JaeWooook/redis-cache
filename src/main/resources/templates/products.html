Redis 캐시 데모

Lettuce(기본) vs Redisson(고트래픽) 비교

Lettuce (기본)
ReactiveRedisTemplate · 단순 Cache-Aside
 Redisson (고트래픽)
RMapCache + RLock · Cache Stampede 방지
Lettuce / ReactiveRedisTemplate
캐시 MISS 시 락 없이 바로 DB 조회. 동시에 N개 요청이 MISS를 만나면 N번 DB 쿼리가 발생합니다. (Cache Stampede 취약)
Redisson / RMapCache + RLock (Double-Check Locking)
MISS 시 분산 락 획득 → 락 대기 스레드는 2차 캐시 재조회 → DB는 오직 1번만 조회. 동시 요청 100개가 와도 DB 쿼리는 1회

캐시 관리

테스트 방법
1. Lettuce 탭에서 조회 → 로그 [CACHE MISS] 확인 → 재조회 → [CACHE HIT]
2. Redisson 탭으로 전환 → 동일하게 조회 → 로그 [REDISSON MISS / HIT] 확인
3. 고트래픽 시뮬레이션: 캐시 삭제 후 브라우저 탭 여러 개에서 동시 요청 → Lettuce는 MISS 여러 번, Redisson은 MISS 1번 + HIT after lock
